# Настройка фронтенда Obuffka

## Быстрый старт

1. **Создайте файл `.env`** в корне папки `obuffka-front`:
```env
VITE_API_URL=https://api.obuffka.ilyacode.ru
```

2. **Установите зависимости**:
```bash
npm install
```

3. **Запустите приложение**:
```bash
npm run dev
```

## Режимы работы

### Режим разработки
В режиме разработки приложение автоматически создает тестового пользователя-администратора:
- ID: 1
- Username: testuser
- Имя: Test User
- Права: Администратор

### Режим Telegram WebApp
Для работы в Telegram:
1. Настройте бота через @BotFather
2. Создайте Mini App и укажите URL вашего приложения
3. Приложение автоматически получит данные пользователя от Telegram

## Возможные проблемы

### Ошибка "Failed to resolve import"
Убедитесь, что все файлы созданы:
- `src/api/api.ts`
- `src/api/axiosInstance.ts`
- Все компоненты в `src/components/`

### Ошибка авторизации
1. Проверьте, что backend запущен
2. Проверьте URL в `.env` файле
3. В режиме разработки приложение должно работать без Telegram

### Не отображаются кнопки админа
Убедитесь, что пользователь имеет права администратора в базе данных.
