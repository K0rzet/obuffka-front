```bash

```

2. **Установите зависимости**:
```bash
npm install
```

3. **Запустите приложение**:
```bash
npm run dev
```

## 🔍 Диагностика проблем:

### 1. Проверка Backend API
Откройте файл `check-backend.html` в браузере для проверки доступности API endpoints.

### 2. Типичные ошибки и решения:

**❌ 401 Unauthorized / 404 Not Found**
- Backend не запущен или недоступен
- Приложение автоматически переключится на тестовый режим
- Проверьте URL в `.env` файле

**❌ Ошибка компиляции TypeScript**
```bash
# Перезапустите dev сервер
npm run dev
```

**❌ Не видно кнопки админа**
- Проверьте консоль браузера
- Убедитесь, что пользователь создался как админ

**❌ Проблемы с авторизацией в Telegram**
- Откройте DevTools → Console
- Проверьте ошибки в логах
- Приложение должно автоматически переключиться на тестовый режим

## 🔄 Режимы работы:

### Telegram WebApp (Продакшн)
- Авторизация через реальные данные Telegram
- При ошибках backend → автоматический fallback на тестовый режим
- Полная функциональность CRM и управления товарами

### Тестовый режим (Разработка)
- Автоматическое создание тестового админ-пользователя
- Все функции доступны без backend
- Отображение ошибок с кнопками повтора

### Offline режим
- При полной недоступности backend
- Показ информативных сообщений об ошибках
- Возможность повторных попыток подключения

## 📱 Telegram WebApp:
Для работы в Telegram нужно настроить Mini App через @BotFather и указать URL вашего приложения.
