## 🔧 Запуск:

1. **Создайте файл `.env`**:
```bash
echo "VITE_API_URL=https://api.obuffka.ilyacode.ru" > .env
```

2. **Установите зависимости**:
```bash
npm install
```

3. **Запустите приложение**:
```bash
npm run dev
```

## 🎯 Что должно работать:

✅ **Режим разработки**: Автоматически создается тестовый админ-пользователь  
✅ **Экраны состояний**: Загрузка → Авторизация → Главная страница  
✅ **Админ панель**: Кнопка "Админ панель" в навигации  
✅ **Управление товарами**: Создание, редактирование, удаление  
✅ **CRM система**: Чаты с клиентами в реальном времени  

## 🐛 Если что-то не работает:

1. **Ошибка компиляции TypeScript** → Перезапустите `npm run dev`
2. **Не видно кнопки админа** → Проверьте, что пользователь создался как админ
3. **Ошибки API** → Проверьте, что backend запущен
4. **Проблемы с авторизацией** → Откройте DevTools и посмотрите ошибки в консоли
